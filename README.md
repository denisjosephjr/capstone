# Capstone (IAS-DAS)

Intelligent Assignment Similarity and Derivation Analysis System (IAS-DAS)
----------------------------------------------------------------------------
Objective: 
Design and develop an intelligent decision-support system for analyzing 
student assignments to identify potentially similar or derived submissions. 

The system will explore techniques that go beyond traditional text 
matching by examining different forms of similarity and potential 
AI-assisted transformations. 

The framework is intended to be generalized to different types of assignments,
with programming assignments serving as the initial implementation and 
evaluation domain.
